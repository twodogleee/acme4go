# 管理端操作与交互规范

本次优化覆盖全部业务管理页面及登录、未找到页，保留现有配色和信息架构，统一操作入口、视觉层级与布局。共同组件为 `frontend/src/components/AppButton.vue`，操作区间距由全局 `action-group` 维护。

## 按钮层级

| 场景 | 样式 | 尺寸与图标 |
| --- | --- | --- |
| 页面新增、表单保存、提交 | 主色实心 | 标准 40px 高，图标和文字并列 |
| 刷新、查询、查看、编辑、取消 | 中性描边 | 页面和表单 40px，卡片标题和记录操作 32px |
| 立即部署、立即同步 | 主色描边 | 列表中 32px，与旁边的详情、编辑同高 |
| 删除、撤销 | 红色描边 | 保留原有确认步骤，显示完整动作文字 |
| 展开记录 | 中性描边 | 固定最小宽度，展开后箭头旋转；收起不改变操作列宽度 |

同一动作固定图标，不按页面或文案临时改变。同一页面的主操作维持清晰层级，列表不混用实心、无框文字和浅色块。

## 布局

- 表格操作列明确标注“操作”，操作采用“详情 → 执行（如有）→ 编辑 → 删除”的稳定顺序。
- 同组按钮按中心线对齐，统一 8px 间距。表格操作保持一行，宽表格在自身区域横向滚动；卡片操作可按完整按钮换行。
- 云部署桌面固定右侧操作列；手机解除固定，防止按钮遮挡域名、状态和证书信息。
- 文件部署操作位于目标信息下方，移除原来的竖排操作；删除由单图标补全为“图标 + 删除”。
- 凭据卡片删除按钮不再通过自动外边距单独推到另一边，整组从同一位置排列。
- 卡片标题使用紧凑按钮，页面工具栏和筛选输入使用标准高度；弹窗底部保留取消在左、主操作在右。
- 证书统计区使用可收缩网格，避免中等屏宽下整页横向溢出。

## 交互与例外

- 保留显式详情按钮；记录详情原位展开，不新增嵌套弹窗。
- 表单提交目标、事件和无障碍属性透传；加载时展示进度并禁用原生按钮，避免重复提交，同时保留调用方的禁用条件；危险操作继续先确认。
- 业务按钮显示文字；导航菜单开关、退出入口、弹窗右上角关闭、分页与选择器内部控件保留其专用紧凑交互。纯图标控件保留可访问名称。
- 路径复制保留完整路径文本与复制图标；证书材料下载保留文件名的双行说明。
- 键盘焦点可见，展开按钮支持 Enter / Space，减少动态效果偏好下关闭箭头动画。

## 验证边界

通过构建、ESLint、注释审计及模拟 API 的浏览器检查。布局检查覆盖 1600、1024、768、390px 下的 11 个管理页面，检查按钮图标、文字、尺寸、重叠、对齐和整页溢出；另检查确认取消、详情、原位展开、键盘交互和表单提交。

浏览器验证使用模拟数据，不更改真实云资源、生产配置或通知。源代码与本地构建的更新不等于已部署到运行中的服务。
