# 只读详情展示规范

管理端统一使用“分组标题 + 字段说明表”。对象详情、原位展开的执行记录和选择器摘要复用 `DetailFields`，保留现有详情入口、查询范围和执行行为。

## 字段与内容

- 标签在左侧浅色区域，值在右侧内容区域；边界、内边距和文字层级一致。
- 宽区域每行容纳两组字段；小弹窗、窄侧栏和手机按组件实际宽度改为单组，保持标签和值的对应关系。
- 奇数项或整行字段之前的落单项自动占满一行，不产生大块空白单元格。
- 分组由业务页显式提供，例如“配置概览 / 部署资源 / 证书来源”或“执行信息 / 证书关联 / 执行结果”。组件不猜测业务类型。
- 域名集合逐项显示并换行；路径、指纹、完整错误和结果说明独占整行。ID 和指纹采用等宽字体，不截断。
- 状态复用统一徽标及中文文案；已停用使用中性色，失败原因用语义颜色突出，同时保留完整文字。
- 空值统一显示破折号；数字零照常显示。文本始终转义，不解释结果中的 HTML。
- 手机宽表中的展开详情限制到视口可读宽度，列表仍在自己的区域横向滚动。

## 已接入的位置

证书、申请、证书系列、凭据、Agent、文件部署目标、云上传规则与部署目标；文件部署、云部署、审计和告警的展开记录；本地及云端证书选择摘要；系统设置的节点运行信息。

申请执行时间线保留时间顺序，证书下载和关联记录保留独立操作区，其标题层级与字段分组统一。查看详情不增加真实部署、查询秘密或发送通知的行为。

## 验证

前端构建、ESLint 和注释审计；模拟 API 的桌面及手机浏览器检查覆盖字段边界、长内容、换行、状态、空值、零值、安全文本、原位展开与选择器摘要。检查不改变真实云资源或生产配置。
