## 展示与数据边界

- 通用 `DetailFields` 只接收页面显式选出的字段，以文本渲染并保留换行；长标识和路径允许换行。
- 对象详情从当前列表按 ID 获取，刷新后显示最新数据；记录展开直接使用当前记录，不建立过时快照。
- 保持现有分页和历史范围：文件部署页仍展示最近 16 条记录，云目标详情仍只展示当前记录页里的关联任务；本次不扩展查询范围或新增后端接口。
- 凭据详情只显示脱敏标识，DNS 测试结果不代表云部署权限校验通过。
