# 文件部署：自动检查与手动同步

“立即同步”同时适用于 Server 本机执行器和远程 Agent。自动部署开关控制持续跟随证书版本，手动同步只执行一次，不会打开自动部署开关。

| 操作 | Server 本机 | 远程 Agent |
| --- | --- | --- |
| 自动检查 | 在维护周期内校验当前版本和磁盘文件；正常则跳过 | 在拉取周期内检查配置修订、证书指纹和磁盘文件；正常则跳过 |
| 立即同步 | 请求中完成文件写入和结果登记 | 持久登记单次请求，Agent 下次拉取后执行 |
| 暂停自动部署 | 不执行周期部署，仍可手动同步 | 不下发常规部署期望；手动请求临时授予该目标所需证书的下载权限 |
| 文件损坏 | 自动部署启用时修复，记录实际部署结果 | 自动部署启用时修复并上报；也可显式手动同步 |

## 页面状态

远程点击后显示“等待 Agent”，表示请求已写入控制面数据库，尚未确认开始。Agent 接收并通过当前修订校验后显示“同步执行中”；收到终态回执后显示成功或失败。页面在存在活动手动请求时每五秒静默刷新，任务结束后停止轮询。

Agent 默认每三十秒拉取一次，实际由 `ACME_AGENT_POLL_INTERVAL` 配置。离线时请求保留，控制面重启也不会丢失。执行中断但未收到终态时，页面继续等待回执，Agent 恢复后重新对账。

暂停自动部署的目标，在单次成功或失败回执送达后结束临时授权，不再持续部署。失败后可以再次点击；若自动部署仍启用，Agent 原有退避重试机制继续生效。

## 并发与取消

重复点击复用未完成请求，不连续增加修订。新手动请求递增目标修订号，因此即使证书未变化也会执行一次。Agent 上报必须匹配当前节点、目标、修订、证书与指纹；旧回执无法覆盖新配置。

修改目标配置会取消旧的单次请求。停用证书系列或撤销 Agent 也会终止相关手动授权。取消不能撤销远程已经完成的文件写入；控制面会拒绝其过期回执，后续按新的有效配置处理。

## 部署记录与升级

本机正常自动检查不重写 PEM、不新增成功记录、不刷新“最后切换”。新版本、配置变化、文件修复或显式手动同步才执行写入并登记结果。以前产生的重复历史记录保留。

本次数据库迁移版本为 8，新增 `deployment_targets.manual_sync`，保留现有目标和记录。请更新 Server 和 Agent 到包含本次修改的同一版本。旧 Agent 可以依靠修订变化执行并上报终态，但不会上报新增的“执行中”阶段；完整状态展示需要新 Agent。

本次验证使用临时数据库、真实合成证书文件和模拟 HTTP 传输，覆盖并发入队、暂停单次授权、过期回执拒绝、开始确认、重启补报、本机跳过与自愈。生产节点的更新和实际同步验收需在升级后执行。
